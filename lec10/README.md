## 1. 포인터란?

- **포인터(pointer)** : 주소를 가지고 있는 변수
- 변수는 메모리에 저장되고, 메모리는 **바이트 단위**로 액세스됨 (첫 바이트 주소 0, 다음 1, ...)
- 변수의 크기만큼 메모리를 차지 : `char` 1바이트, `int` 4바이트, `double` 8바이트

---

## 2. 포인터 연산자 2가지 ⭐

| 연산자 | 이름 | 의미 | 예 |
|---|---|---|---|
| `&` | 주소 연산자 | 변수의 **주소**를 계산 | `&number` |
| `*` | 간접 참조 연산자 | 포인터가 **가리키는 곳의 값** | `*p` |

```c
int number = 10;   // 정수형 변수
int *p;            // 포인터 변수 선언
p = &number;       // number의 주소를 p에 대입 -> p가 number를 가리킨다

printf("%d", *p);  // 10
*p = 20;           // number가 20이 됨
```

| 수식 | 값 |
|---|---|
| `number` | 10 |
| `&number` | number의 주소 |
| `p` | number의 주소 (`&number`와 같음) |
| `*p` | 10 (`number`와 같음) |
| `&p` | 포인터 변수 p 자신의 주소 |

- 선언의 `*`(`int *p;`)는 "포인터 변수다"라는 표시, 사용할 때의 `*`(`*p`)는 "가리키는 값"
- `int* p`도 맞는 표현

## 3. 포인터 연산 ⭐

- 가능한 연산 : **증가, 감소, 덧셈, 뺄셈**
- 포인터를 1 증가시키면 **가리키는 자료형의 크기만큼** 증가

| 포인터 | `p++` 후 (10000에서 시작) | `p + 2` |
|---|---|---|
| `char *` | 10001 | 10002 |
| `int *` | 10004 | 10008 |
| `double *` | 10008 | 10016 |

### 간접 참조 연산자와 증감 연산자 ⭐

| 수식 | 의미 |
|---|---|
| `v = *p++` | p가 가리키는 값을 v에 대입한 후에 **p를** 증가 |
| `v = (*p)++` | p가 가리키는 값을 v에 대입한 후에 **가리키는 값을** 증가 |
| `v = *++p` | **p를** 증가시킨 후에 p가 가리키는 값을 v에 대입 |
| `v = ++*p` | **가리키는 값을** 증가시킨 후에 그 값을 v에 대입 |

- `*p++` 는 `*(p++)` 로 해석됨 (`*`와 `++`는 우선순위가 같고 오른쪽 → 왼쪽 결합)
- 확인용 코드 : `lec10-pointer_incdec.cpp`

## 4. 함수 호출 시 인수 전달 방법 ⭐

| | 값에 의한 호출 (call-by-value) | 참조에 의한 호출 (call-by-reference) |
|---|---|---|
| 전달되는 것 | 인수의 **값**이 복사됨 | 인수의 **주소**가 복사됨 |
| 원본 변경 | 불가능 | 가능 (`*ptr = 99;`) |
| C에서 | 기본 방법 | 포인터를 이용해서 **흉내 냄** |
| 호출 | `modify(number);` | `modify(&number);` |
| 정의 | `void modify(int value)` | `void modify(int *ptr)` |

- 큰 데이터를 통째로 복사하는 대신 주소(페이지 번호)만 알려주는 것이 효율적
- `swap()` 은 값에 의한 호출로는 실패, 포인터로 해야 성공 → `lec10-swap.cpp`
- `scanf("%d", &x);` 에 `&` 를 붙이는 이유도 같음

## 5. 포인터 사용 시 주의점 ⭐

### (1) 초기화가 안 된 포인터를 사용하면 안 된다

```c
int main(void)
{
    int *p;      // 포인터 p는 초기화가 안 되어 있음 (쓰레기 주소)
    *p = 100;    // 위험한 코드! 어디인지 모르는 메모리에 씀
    return 0;
}
```

### (2) 아무것도 가리키지 않을 때는 NULL로 초기화

```c
int *p = NULL;   // NULL : 0번지, 일반 사용자 금지구역
```
- NULL 포인터를 간접 참조하면 하드웨어가 감지할 수 있음 (프로그램이 바로 멈춰서 오류를 찾기 쉬움)
- 포인터가 유효한지 판단하기 쉬움 : `if (p != NULL) ...`

### (3) 포인터의 타입과 변수의 타입은 일치해야 한다

```c
int i;
double *pd;
pd = &i;      // 오류! double형 포인터에 int형 변수의 주소를 대입
*pd = 36.5;   // int(4바이트) 자리에 double(8바이트)을 씀 -> 옆 메모리까지 망가짐
```

## 6. 배열과 포인터 ⭐

- **배열 이름 = 첫 번째 요소의 주소** : `a == &a[0]`
- 포인터는 배열처럼, 배열은 포인터처럼 사용 가능

```c
int a[] = { 10, 20, 30, 40, 50 };
int *p = a;
```

| 같은 것 | |
|---|---|
| `a[i]` | `*(a + i)` |
| `p[i]` | `*(p + i)` |
| `&a[i]` | `a + i` |

- 차이 : `p` 는 변수라서 `p++` 가능, `a` 는 상수라서 `a++` **불가능**
- 함수에 배열을 넘기면 **주소만** 전달됨
  - `void f(int values[], int n)` == `void f(int *values, int n)`
  - 함수 안에서는 배열 크기를 모르므로 크기 `n` 을 따로 넘김
  - 함수 안에서 배열 요소를 바꾸면 **원본 배열도 바뀜**
