## 1. 함수의 정의 구조

```c
int add(int x, int y)   // 반환형  함수이름(매개변수)
{                       // 함수 몸체 시작
    int result;         // 지역 변수
    result = x + y;
    return result;      // 반환값
}                       // 함수 몸체 끝
```

| 구성요소 | 설명 |
|---|---|
| 반환형 | 함수가 돌려주는 값의 자료형 (`int`, `double`, `char` ...). 반환값이 없으면 `void` |
| 함수 이름 | 보통 **동사 + 명사** : `square()`, `compute_average()`, `get_integer()` |
| 매개변수 | 외부로부터 전달받는 데이터를 저장하는 변수 |
| 지역 변수 | 함수 안에서 정의되는 변수 |

- 함수 = 입력을 받아서 작업한 후 결과를 생성하는 **블랙박스 / 부품(레고 블록)**
- 하나의 프로그램은 여러 함수가 모여서 이루어짐

## 2. 함수 호출과 반환

- **함수 호출** : 함수 이름을 적어 주는 것
  1. 함수 안의 문장들이 순차적으로 실행된다
  2. 실행이 끝나면 **호출한 위치로 되돌아간다**
  3. 결과값을 전달할 수 있다
- **반환값은 하나만** 가능 (인수는 여러 개 가능)

```c
return 0;
return (x);
return x + y;
return;        // void 함수 : 값 없이 종료
```

## 3. 인수 vs 매개변수 ⭐

| | 인수 (argument) | 매개변수 (parameter) |
|---|---|---|
| 다른 이름 | 실인수, 실매개변수 | 형식 인수, 형식 매개변수 |
| 위치 | 함수를 **호출**할 때 넘기는 값 | 함수 **정의**의 괄호 안 변수 |
| 예 | `get_max(a, b)` 의 `a`, `b` | `int get_max(int x, int y)` 의 `x`, `y` |

- 인수의 값이 매개변수로 **복사**되어 전달됨 → 함수 안에서 매개변수를 바꿔도 원래 변수는 안 바뀜
- 개수와 타입이 맞아야 함

```c
get_max(10);         // X : 인수가 두 개여야 한다
get_max(0.1, 0.2);   // X : 인수의 타입은 정수여야 한다
get_max();           // X : 인수가 두 개여야 한다
```

## 4. 함수 원형 (function prototype) ⭐

- 컴파일러에게 함수에 대하여 **미리 알리는 것**
- `main()` 보다 **아래에** 정의된 함수를 호출하려면 `main()` 위에 원형 필요
- 끝에 **세미콜론**, 매개변수 이름은 생략 가능

```c
int compute_sum(int n);   // 원형
int check_prime(int);     // 매개변수 이름 생략 가능
```

- 함수를 `main()` 위에 먼저 정의하면 원형이 없어도 됨

## 5. 지역 변수 / 전역 변수 / 정적 지역 변수 ⭐

| | 지역 변수 | 전역 변수 | 정적 지역 변수 (`static`) |
|---|---|---|---|
| 선언 위치 | 함수(블록) 안 | 함수 밖 | 함수(블록) 안, 앞에 `static` |
| 사용 범위 | 그 함수(블록) 안에서만 | 모든 함수 | 그 함수(블록) 안에서만 |
| 생성 / 소멸 | 함수 호출 시 생성, 종료 시 삭제 | 프로그램 시작 ~ 종료 | 프로그램 시작 ~ 종료 (값 유지) |
| 초기화 안 하면 | **쓰레기 값** | **0** | **0** |
| 초기화 횟수 | 호출할 때마다 | 한 번 | **한 번** |

### 지역 변수의 사용 범위

```c
int sub1()
{
    int x;      // x 는 sub1 안에서만 유효
    ...
}

void sub2()
{
    printf("%d \n", x);   // 에러! x 는 sub1 의 지역 변수
}
```

### 지역 변수 초기값 함정

```c
int compute_sum(int n)
{
    int i, result;            // result 초기화 안 함 -> 쓰레기 값
    for (i = 0; i <= n; i++)
        result += i;          // 쓰레기 값에 더함 -> 잘못된 결과
    return result;
}
```
→ `int result = 0;` 으로 반드시 초기화

### 전역 변수를 권장하지 않는 이유

- 어디서나 접근 가능하다는 장점이 오히려 단점
- 프로그램이 복잡해지면 **어디서 값을 바꿨는지 알기 어려움**

### 같은 이름이면?

```c
int sum = 123;       // 전역 변수

int main(void)
{
    int sum = 321;   // 지역 변수
    printf("sum=%d \n", sum);   // 321 : 지역 변수가 전역 변수를 가린다
}
```

## 6. 순환 호출 (recursion) ⭐

- 함수가 **자기 자신을 호출**하여 문제를 해결하는 기법
- 반드시 **멈추는 조건**이 필요 (없으면 무한 호출)

```c
int factorial(int n)
{
    if (n <= 1) return 1;                 // 멈추는 조건
    else return n * factorial(n - 1);     // 문제를 작게 만들어서 자기 호출
}
```

```
factorial(3) = 3 * factorial(2)
             = 3 * 2 * factorial(1)
             = 3 * 2 * 1
             = 6
```
- 호출 순서 : 3 → 2 → 1, 반환(계산) 순서 : 1 → 2 → 3

## 7. 라이브러리 함수

- 컴파일러에서 제공하는 함수 : 표준 입출력, 수학 연산, 문자열 처리, 시간 처리, 오류 처리, 데이터 검색과 정렬

### 수학 함수 `<math.h>` (모두 double 반환)

| 함수 | 설명 | 사용 예 | 반환값 |
|---|---|---|---|
| `sin(x)` | 사인 | `sin(3.14/2.0)` | 1.0 |
| `cos(x)` | 코사인 | `cos(3.14/2.0)` | 0.0 |
| `tan(x)` | 탄젠트 | `tan(0.5)` | 0.546302 |
| `exp(x)` | e^x | `exp(10.0)` | 22026.5 |
| `log(x)` | log_e x | `log(10.0)` | 2.30259 |
| `log10(x)` | log_10 x | `log10(100.0)` | 2.0 |
| `ceil(x)` | x보다 작지 않은 가장 작은 정수 (올림) | `ceil(3.8)` | 4.0 |
| `floor(x)` | x보다 크지 않은 가장 큰 정수 (내림) | `floor(3.8)` | 3.0 |
| `fabs(x)` | 절대값 | `fabs(-3.67)` | 3.67 |
| `pow(x, y)` | x^y | `pow(3.0, 2.0)` | 9.0 |
| `sqrt(x)` | 제곱근 | `sqrt(4.0)` | 2.0 |

### 난수 `<stdlib.h>`, `<time.h>`

- `rand()` : 0 ~ `RAND_MAX` 사이 난수
- `1 + (rand() % 45)` : `rand() % 45` 는 0 ~ 44 → 전체는 **1 ~ 45**
- `srand(time(NULL));` : 현재 시각을 **시드(seed)** 로 설정 → 실행할 때마다 다른 난수
  - 시드를 안 바꾸면 매번 같은 난수가 나옴 (예: 41 18467 6334 26500)
